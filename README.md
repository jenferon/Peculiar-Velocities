# Peculiar-Velocities
Code I have used to determine the combined affect of peculiar velocities and the lightcone effect on simulations of 21cm photos during the epoch of reionisation.

capeability to count the number of events which originate from a different frequency slice and box to the 'standard method' have been added, as well as capability to count the number events used for each pixel. This was done in order to quantify the difference between the full and standard approach.

This work follows on from https://arxiv.org/abs/1909.12859 .
